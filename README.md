# Asfand Amjad — Portfolio

A professional and dynamic personal portfolio website built with Django.

## About

This portfolio showcases my:

- About
- Skills
- Projects
- Experience
- Education
- Achievements
- Contact information

## Features

- Dynamic content management through Django Admin
- Responsive design for desktop, tablet, and mobile
- Dark and light mode
- Project showcase
- Resume download
- Contact form
- PostgreSQL database
- Accessible and SEO-friendly structure

## Tech Stack

- Python
- Django
- PostgreSQL
- HTML
- CSS
- JavaScript
- Git & GitHub
